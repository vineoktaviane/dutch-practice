# Dutch Grammar Trainer

A hobby project. The goal is to get better at Dutch.

I kept losing the same grammar points over and over, so I built myself a trainer instead of buying another app. It runs offline as an installable PWA, covers A1-B1 across 18 topics, and generates questions from hand-curated word banks. Spaced repetition works on the underlying fact (`noun:huis:gender`, `verb:kopen:participle`) rather than the question, there is a typed-answer mode because recognising an option is not the same as producing a word, and it speaks the Dutch back at you.

Built for an audience of one. Nothing here is finished; it changes whenever I hit a new thing I keep getting wrong.

```bash
npm install && npm run dev
```
